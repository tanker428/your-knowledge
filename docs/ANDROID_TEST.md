# Android 実機確認手順

対象は **Android Chrome** のみ。iPhone / Safari 固有の対応は行っていない。

## 準備

PCとスマホを同じネットワークに置き、PC側で配信する。

```bash
npm run dev
```

PCのローカルIPを調べ（`ipconfig`）、スマホから開く。

```
http://192.168.x.x:8000/your-knowledge/
```

> **注意**：`http://` ではブラウザが Service Worker を登録しない（`localhost` を除く）。
> PWA・オフライン・共有先の確認は、GitHub Pages へ公開したあと `https://` で行うこと。
> それ以外の項目は `http://` でも確認できる。

---

## 1. 表示

- [ ] 白画面にならず、ホーム画面が表示される
- [ ] サンプル写真が表示される（画像切れが無い）
- [ ] 下部にタブバーが出る（概要／写真／整理／知識／学ぶ／収集）
- [ ] 横スクロールが発生しない
- [ ] 各タブへ移動できる
- [ ] 再読み込みしても404にならない

## 2. 写真の一括読み込み

- [ ] 「＋ 写真を追加」→「写真をここにドロップ」をタップするとギャラリーが開く
- [ ] **複数枚をまとめて選択できる**
- [ ] 選択した枚数だけサムネイルが並ぶ
- [ ] 「未整理で追加」を押すと**進捗バーが動く**（`3 / 20 枚：IMG_0042.jpg` のように出る）
- [ ] 20〜40枚を入れても画面が固まらない
- [ ] 読み込み中に「中止する」を押すと止まる
- [ ] **中止しても、それまでに読み込んだ写真は残っている**
- [ ] 追加した写真は「未整理」と表示される
- [ ] 追加した写真に**勝手な観察対象が付いていない**
- [ ] 「AI解析は未接続」ボタンは押せない状態になっている

### 確認したい失敗パターン

- [ ] 動画やPDFを混ぜて選ぶと、画像だけが取り込まれる
- [ ] 同じ写真を2回選んでも重複しない

## 3. リロード後にデータが残る（最重要）

移植前の版はここが壊れていた（追加した写真がリロードで消えた）。

- [ ] 写真を数枚追加する
- [ ] 整理画面で観察対象をいくつか追加・除外する
- [ ] **ブラウザを完全に閉じて開き直す**
- [ ] 追加した写真がまだある
- [ ] 追加・除外した観察対象の状態が保たれている
- [ ] 写真の画像がちゃんと表示される（灰色や「写真未接続」になっていない）

## 4. タッチ操作だけで整理できる

- [ ] 上部の写真ストリップを横スクロールして写真を選べる
- [ ] 写真の上の番号をタップして対象を選べる
- [ ] 候補カードをタップして採用／除外を切り替えられる
- [ ] 「すべて残す」で一括採用できる
- [ ] 分類チップをタップで選択・解除できる
- [ ] 「全対象の汎用分類を一括確認」が効く
- [ ] ステップ1→2→3→4 と進める
- [ ] **ドラッグ操作を要求される場面が無い**
- [ ] 3カラムではなく、縦に積まれて表示される

## 5. JSON の書き出しと読み込み

- [ ] 写真タブ →「JSONを書き出す」
- [ ] **Androidの共有シートが開く**（Drive・ファイル・メール等が選べる）
- [ ] 共有シートが出ない端末では通常のダウンロードになる
- [ ] 書き出したJSONを開くと `"format": "your-knowledge-project"` がある
- [ ] JSONの中に写真の画像データ（base64）が入っていない
- [ ] 「JSONを読み込む」→ さきほどのファイルを選ぶ
- [ ] 件数の確認ダイアログが出る
- [ ] 読み込み前に控えが自動で書き出される
- [ ] 読み込み後、内容が復元される

### 壊れたファイルの確認

- [ ] 適当なテキストファイルを `.json` にして読み込ませる
- [ ] 「読み込みを中止しました」と理由が表示される
- [ ] **既存のデータが消えていない**

## 6. PWA としてインストール

`https://` での公開後に確認する。

- [ ] Chrome のメニューに「アプリをインストール」/「ホーム画面に追加」が出る
- [ ] インストールするとホーム画面にアイコンが出る
- [ ] アイコンから起動するとアドレスバーが無い状態で開く
- [ ] 起動後、保存したデータがある

## 7. オフライン

- [ ] インストール後、一度アプリを開く
- [ ] **機内モードにする**
- [ ] アプリを起動する → 白画面にならず開く
- [ ] 写真タブで保存済みの写真が見られる
- [ ] 知識マップが見られる
- [ ] 一度も見ていないサンプル写真は表示されないことがある（仕様）

## 8. 共有先として写真を受け取る

Web Share Target。端末とChromeのバージョンによっては利用できない。

- [ ] Googleフォトで写真を複数選択
- [ ] 「共有」→ 一覧に **Your Knowledge** が出る
- [ ] 選ぶとアプリが開き、「◯枚をギャラリーから受け取りました」と出る
- [ ] そのまま「未整理で追加」できる
- [ ] **共有先に出ない場合でも**、アプリ内の「写真を選ぶ」から追加できる

## 9. 保存容量

- [ ] 「＋ 写真を追加」を開くと下部に保存領域の状態が出る
  （例：`永続保存が有効です・使用量 12.4MB / 2.1GB`）
- [ ] インストール済みの場合「永続保存が有効です」になっている
- [ ] 容量が逼迫すると警告バナーが出る

## 10. 更新

- [ ] 新しい版を公開したあとアプリを開く
- [ ] **「新しいバージョンがあります」バナーが出る**
- [ ] 「後で更新」を押すと消え、作業を続けられる
- [ ] **編集中に勝手に更新されない**
- [ ] 「今すぐ更新」を押すと再読み込みされ、新しい版になる

---

## 不具合を見つけたとき

以下を控えておくと調査が早い。

- Android のバージョンと Chrome のバージョン
- インストール済み（ホーム画面から起動）か、ブラウザで開いたか
- 「JSONを書き出す」で書き出したファイル
- PCと接続して `chrome://inspect` で開いたコンソールの内容
